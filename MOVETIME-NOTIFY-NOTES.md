# Время хода и уведомление о ходе в заочной партии (2026-10-22): заметки для документации

## Время хода

- `play.MoveRec` получила `ms` (сколько игрок думал, мс; не меньше 1, 0 = «не записано», как в старых партиях) и `left` (часы после хода с добавкой, мс, только партии с часами). Оба `omitempty`, состояние `state` старых партий читается как раньше. Заочные: `ms` — реальное ожидание, дни включены, `left` нет. Снимок (`View.Moves`) отдаёт оба поля.
- `Game.PGN()` пишет к каждому ходу `{[%clk h:mm:ss] [%emt h:mm:ss]}` (clk — остаток, emt — время хода; доли секунды только если есть), чёрный ход после комментария получает номер `N...`. У заочной партии тег `[TimeControl "1/<секунд на ход>"]`, clk нет. Старая партия без времени пишется без комментариев.
- `pgn`: `Move.Spent` читается из `[%emt ...]` (отрицательно, если нет), `Game.String()` пишет его обратно.
- `analysis/times.go`: `moveTimes` — время каждого хода: сначала `emt`; иначе по `clk` (прошлый остаток той же стороны + добавка − остаток сейчас; первый ход от базы тега `TimeControl` вида `300` или `300+3`); если добавку тег не даёт, она угадывается по парам (наибольший рост часов между двумя ходами одной стороны, не больше 180 с); без базы времени первых ходов нет. В отчёте `MoveReport.TimeMs *int64` (`timeMs`, опционально). Старые разборы в БД открываются как раньше. Варианты (`vplay`, Chess960) не затронуты.
- Сайт: настройка `showMoveTime` («Игровой процесс → Анализ», по умолчанию выкл). Время рядом с ходом в списке ходов партии (`online/GameRoom.jsx`, `MoveListing`) и разбора (`review/MoveList.jsx`), компонент `online/MoveTime.jsx`, формат `online/moveTime.js` («2,3 с», «23 с», «1:05», «1 ч 20 м», «2 д 3 ч»), блок «Время на ход» во вкладке «Итог» (`review/TimeSection.jsx`: среднее по сторонам и три самых долгих хода, нажатие открывает ход). Стили в `online/movetime.css`.

## Уведомление о ходе в заочной партии (`web/src/notify/`)

- `useCorrNotify(summary, userId, notify)` вызывается одной строкой в `community/CommunityContext.jsx`. Число `summary.yourTurn` идёт в заголовок вкладки: «(2) Dyanis Chess». Когда число выросло (первый ответ после загрузки не считается): список `GET /api/community/correspondence` (бэкенд не менялся) показывает, в каких партиях ход новый (`logic.js: freshTurns`, сравнение по числу полуходов) и кто соперник; партия, комната которой открыта на экране, пропускается. Звук `notify` (`sound.js`, Web Audio, три ноты) играет при `sound && corrNotifySound`; системное уведомление (`system.js`) только при скрытой вкладке и `corrNotifyBrowser`; при видимой вкладке вместо него маленькое окошко в углу (`notify` провайдера) с кнопкой «Играть». Если оба выключены, ничего не показывается (заголовок остаётся).
- Вкладка в фоне не опрашивает сводку, поэтому у человека, у которого есть заочные партии, хук при сворачивании вкладки один раз обновляет число и затем опрашивает `GET /api/community/summary` раз в 20 с. Это же показывает его друзьям «в сети». Браузеры сильно притормаживают таймеры фоновых вкладок (Chrome примерно до раза в минуту), уведомление может прийти позже.
- `unlockAudio()` создаёт AudioContext по первому нажатию на странице, чтобы звук без жеста был слышен.
- Настройки (`model.js`, `GAMEPLAY_KEYS`): `corrNotifySound` (вкл), `corrNotifyBrowser` (выкл), `showMoveTime` (выкл). Разрешение браузера просится только при включении переключателя «Уведомления о ходе» (`NotifyRows.jsx`, «Игровой процесс → Заочные партии»); отказ показывает подсказку, переключатель остаётся выключенным. Кнопка «Проверить» проигрывает звук.
- Словарь `notify` в `i18n/ru/notify.js` и `i18n/en/notify.js` (подключён в `i18n/ru.js` и `en.js`; если агент перевода перегенерирует эти файлы, строку `d_notify` нужно сохранить).

## Проверено

Тесты: `play` (время в снимке и состоянии, старая партия без времени, PGN с clk/emt, заочная без clk), `pgn`, `analysis` (времена из clk, без добавки, угаданная добавка, emt, пропущенный clk, отчёт), `npm test` (`notify/logic`, `online/moveTime`). Edge, две сессии: ходы онлайн показывают «3,9 с / 1,7 с»; разбор показывает время в списке и «Время на ход» в «Итоге»; заочная: звук (три осциллятора), заголовок «(1) Dyanis Chess», окошко «Ваш ход в заочной партии против …», при «скрытой» вкладке системное уведомление через 17 с (Notification и AudioContext подменены).

Не проверено: настоящий запрос разрешения (в headless Edge окно не появляется, ответ остался «default»), реальные системные уведомления и звук на экране автора, тяжёлое замедление таймеров фоновой вкладки, светлая тема и телефон, партии с ботами в браузере (проверены только тестами через общий `Game.Move`).

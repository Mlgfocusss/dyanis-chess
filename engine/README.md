# Движок

Шахматный движок Dyanis: правила, поиск, ручная и нейросетевая (NNUE) оценка, UCI,
инструменты обучения и матчей. Он отделён от сайта: всё, что связано с сервером, лежит
в [`../backend/`](../backend), интерфейс — в [`../web/`](../web).

Команды движка выполняются **из этой папки** (`cd engine`): пути в документах
[`TECHNICAL.md`](./TECHNICAL.md), [`NNUE.md`](./NNUE.md) и [`plan.md`](./plan.md)
(`cmd/…`, `assets/…`, `data/…`, `train/…`, `net-kingf-m4.bin`) отсчитываются отсюда.
Python-окружение `.venv` лежит в корне репозитория (`../.venv`).

```
engine.go, engine_test.go   фасад движка (см. ниже)
internal/                   устройство движка; снаружи engine/ его импортировать нельзя
cmd/                        cli, match, gendata, nnuetool, tune, spsa, profile, wasm
train/                      обучение сети (PyTorch), экспорт в формат движка
assets/                     книги дебютов (.bin)
net-kingf-m4.bin            текущая сеть (заморожена)
nets-archive/               прежние сети
data/, spsa-nnue/, engines/ данные обучения, результаты SPSA, чужие движки для матчей
                            (в git не входят)
```

## Фасад: единственная дверь к движку

Сервер (`backend/`) знает о движке только то, что описано в [`engine.go`](./engine.go).
Go запрещает импортировать `engine/internal/...` снаружи `engine/`, поэтому это правило
проверяет компилятор, а не договорённость.

Что даёт фасад:

| Что | API |
|---|---|
| позиция | `NewPosition()`, `ParseFEN(fen)`, `FEN()`, `Hash()`, `Copy()`, `SideToMove()` |
| ходы | `LegalMoves()`, `ParseSAN(s)`, `SAN(m)`, `Play(m)`, `Move.String()` (UCI) |
| конец партии | `Outcome(history)`: мат, пат, 50 ходов, повторение, нехватка материала |
| поиск | `Search(pos, history, Limits{Depth \| MoveTime+MaxDepth, HashMB})` → `Result{Best, Score, Depth, Nodes, PV}` |
| сеть | `LoadNetwork(path)` |
| константы | `StartFEN`, `MateScore` |

Правила пользования результатом поиска:

- `Score` — в сантипешках с точки зрения стороны, которая ходит; мат — это
  `±(MateScore − n)`, где `n` — число полуходов до мата. Всё, что по модулю не меньше
  `MateScore − 1000`, считается матом.
- `Hash` у одинаковых позиций одинаков всегда (его используют для перестановок
  дебютов и для повторений).
- Поиск при `Depth > 0` воспроизводим: тот же результат на любой машине.
- `Search` можно вызывать из нескольких горутин сразу, каждый вызов однопоточный.

## Как заменить движок

1. Оставьте экспортируемый API `engine.go` как есть и поменяйте то, что за ним: либо
   перепишите `engine/internal/...`, либо замените реализацию на запуск UCI-программы
   подпроцессом (тогда правила шахмат — позиции, SAN, легальные ходы — придётся реализовать внутри фасада самим).
2. Прогоните `go test ./engine/` — это тесты контракта (позиции, SAN, окончание партии,
   поиск мата в один ход, воспроизводимость, ошибка на позиции без ходов). Если они
   проходят, `backend/` ничего не заметит.
3. Если файл сети называется иначе или сети нет, поменяйте `NET_FILE` в
   `deploy/Dockerfile.server` (или передайте `--build-arg NET_FILE=...`).
4. Браузерный бот собирается из `engine/cmd/wasm` (`deploy/Dockerfile.web` делает это сам).
   Если у нового движка нет такой сборки, бот просто остаётся на старом.

Вне `engine/` менять не нужно ничего, кроме, возможно, `deploy/` из пункта 3.

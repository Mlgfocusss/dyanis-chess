# Значки оценки ходов

Сюда кладутся картинки значков. Если для класса есть файл, сайт показывает его вместо нарисованного
значка (в списке ходов, на доске, в карточке хода, в таблице точности). Классы без файла остаются со
старым значком, так что папку можно наполнять по одной картинке.

## Имена файлов

Имя файла равно имени класса, расширение любое из `svg`, `png`, `webp`, `jpg`, `avif`:

| Файл | Значок |
|---|---|
| `brilliant` | блестящий ход (!!) |
| `great` | сильный ход (!) |
| `best` | лучший ход |
| `excellent` | отличный ход |
| `good` | хороший ход |
| `book` | теория (дебютный ход) |
| `inaccuracy` | неточность (?!) |
| `miss` | упущенная возможность: соперник ошибся, а вы не воспользовались (неточность или ошибка сразу после его ошибки) |
| `mistake` | ошибка (?) |
| `blunder` | зевок (??) |

Например `brilliant.svg`, `blunder.png`.

## Требования к картинкам

- **Квадрат**, лучше **SVG** (чёткий на любом размере). Для PNG или WebP: не меньше 128×128 пикселей.
- **Прозрачный фон**, значок круглый или с готовой формой: сайт ничего не подкрашивает и не обрезает.
- Один и тот же значок показывается и мелко (22 px в списке ходов), и крупно (на углу поля доски и в
  карточке хода), поэтому детали должны читаться в маленьком размере.
- Лицензия: только свои или те, что можно использовать (как и для остальных наборов в `web/src/themes/`).

После добавления файлов пересоберите сайт: `docker compose up -d --build web`.

# Темы: фигуры, доски, фоны, звуки

Сюда кладутся картинки и звуки для страницы «Настройки → Доска и фигуры». Код править не
нужно: достаточно положить файлы в нужную папку и **пересобрать сайт** (в Docker —
`docker compose up -d --build web`, при `npm run dev` страница обновится сама).

Всё лежит внутри `web/src/themes/`. Папку `web/public/` и папку движка `engine/assets/`
(там книги дебютов) трогать не надо.

## Фигуры — `pieces/<название набора>/`

Одна папка = один набор. В папке нужны **12 файлов** (регистр букв не важен, расширение любое
из `svg png webp jpg jpeg gif avif`; лучше SVG или PNG с прозрачным фоном, квадратные):

```
wP wN wB wR wQ wK     белые: пешка, конь, слон, ладья, ферзь, король
bP bN bB bR bQ bK     чёрные
```

Пример: `pieces/cburnett/wK.svg`, `pieces/cburnett/bQ.svg`, ... Название папки становится
названием набора в списке (`my-set` → «My set»). Если файлов не хватает, набор не
показывается, а на вкладке «Фигуры» появляется предупреждение, каких именно нет.

## Доски — `boards/`

Два варианта:

- **Картинка всей доски**: файл `boards/<название>.png` (или `jpg webp svg`) — квадрат 8×8
  клеток целиком.
- **Две текстуры клеток**: папка `boards/<название>/` с файлами `light.*` (светлая клетка) и
  `dark.*` (тёмная).

Простые цветные доски зашиты в `index.js` (массив `colorBoards`), там же можно добавить свои
пары цветов.

## Фоны — `backgrounds/`

Файлы `jpg png webp svg avif` прямо в папке: `backgrounds/forest.jpg`. Поверх фото
накладывается тёмная вуаль, чтобы текст оставался читаемым. Берите картинки от 1920×1080,
тёмные или спокойные, не тяжелее 1–2 МБ.

## Звуки — `sounds/<название темы>/`

Файлы `mp3 ogg wav m4a` с именами:

```
move  capture  check  castle  promote  end  start
```

(ход, взятие, шах, рокировка, превращение, конец партии, начало). Нужны не все: чего нет, то
играет стандартный синтезированный звук. Тема «Стандартная» работает без файлов.

## Лицензии

Перед тем как класть чужие наборы фигур, доски и звуки в репозиторий, проверьте лицензию и
рядом с набором положите `LICENSE.txt` или `CREDITS.txt` с автором и ссылкой на источник.
Свободные (CC0, CC-BY) подходят без ограничений, но автора нужно указать; наборы под GPL или
CC-BY-SA накладывают условия на распространение, для публичного сайта их стоит читать
внимательно. Фигуры, доски и звуки chess.com защищены авторским правом: для личного
просмотра на своём компьютере это одно, для выкладывания на публичный сайт другое. У lichess
много свободных наборов фигур (репозиторий lichess-org/lila, папка `public/piece`, у каждого
набора своя лицензия).
